# 审核

入库建的是**骨架卡**——题面、选项、正解、标准答案都还空着。这一页把它们一道道转录成记录。

<ReviewQueue />

## 三条规矩

:::note 转录是人按的
进这一页**什么都不发生**。每次模型调用都由你按一下「跑一次转录」触发，
所以钱只花在你真的要看的那几张卡上（骨架卡等审核填，ADR 级的理由见 §10.8）。
:::

:::warning 图是准绳
草稿是模型读出来的，可能有错。上面那张整页照片就是它读的东西——**对一遍再保存**。
看不清的地方模型会写在「看不清的地方」那一行里，那是给你核对的，不是给你忽略的。
:::

:::danger 保存只写你动过的字段
服务端把**空串当成"显式清空"**（人能明确说"这道题没有标准答案"）。
所以这一页**不会**把整张表单原样发回去：没动过、草稿里也没有的空字段，一个都不发。
反过来说：**你把题面清空再保存，它就真的空了**——那是有意为之的表达方式。
:::

## 它不做的事

- **不自动转录**：没有任何流程会替你跑（那正是这一版与"入库即转录"的取舍差别）。
- **不印答案到别处**：草稿只在这一页出现；写进卡之后，答案仍然只在阅读页。
- **不替你判断**：`mark_reviewed` 由你勾——不勾就不动审核状态。
