# 重做纸印转录文字，复习纸印照片

> **Status: superseded by [ADR-0005](./0005-redo-sheet-prints-cleaned-photo.md)**（同日推翻：转录方案的代价是「转错一个符号就等于换了一道题」，而擦除手写可以两全——它既保留原件、又不泄露答案。本文保留，因为它记录的替代方案在擦除不可靠时仍会回来。）

## 背景

`2.png` 的考核暴露了一个矩形裁剪躲不开的问题：订正的红笔 A 就写在选项上方，任何包含选项的裁剪框都会把它带进来（`cropcheck` 量到框内有 453 像素彩笔墨迹）。而重做纸一旦印出订正过的正答，**重做的意义就没了**——你会看着答案"重做"。

同时，另一个方向也走不通：手写压在题干区域上时，框躲不开；靠抹白彩笔像素会在题干上留下空洞，还会连题目本身的彩色印刷一起抹掉。

## 决定

- **重做纸印题面转录**（文字重排，数学用 KaTeX），不印照片。
- **复习纸印照片**（题面与手写解答），不印转录。

理由：两张纸的目标不同。重做纸要「不泄露答案 + 干净好写」，照片做不到第一点；复习纸要「回看当时怎么错的」，只有照片做得到，而它本来就不需要保密。

## 后果

1. **转录错一个符号 = 换了一道题**，而你没做错这道题、往往看不出来。审核的门槛因此被抬高：审核的第一件事变成**逐字对照照片确认题面转录**。这条风险由「先入库后审核」兜住——未审核的题不会进重做纸。
2. 转录必须是**可渲染的 LaTeX**。纯文本的上标（`x²`）排不出来。于是抽取模型的输出格式从"偏好"升级为**验收项**。
   （观测：`deepseek-v4-flash-vision-exp` 天然输出 LaTeX，`deepseek-flash` 默认输出纯文本，需要提示词约束。）
3. 选择题要靠文字重排选项，所以题卡需要把选项拆成结构，不能只留一整段文字。
4. 复习纸要展示手写，需要**第二个框**：含学生手写解答的区域。目前只存了题干的框。
5. 附带好处：有了文字就能按字符数与行数估高度，重做纸的版面格初猜比照片时代容易得多。

## 考虑过的替代方案

- **两张都印照片**：最简单、绝不改变题意，但要接受重做纸上带着手写痕迹。
- **照片裁剪 + 把框内彩笔抹白**：能防泄露，但会在题干上留空洞，且会抹掉题目本身的彩色印刷——用一个新错误换掉旧错误。
