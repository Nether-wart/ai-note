# 生产形态：以 Docusaurus 为基，并保持可编译为 Tauri 应用

## 背景与决定

要求：项目以 Docusaurus 为基础，且要能方便地编译为 Tauri 应用。

这**不是改方向**。[ADR 0001](0001-file-backed-data-with-write-service.md) 定的就是「Docusaurus 只负责渲染与打印排版，数据变更永不触发 Docusaurus 重建」，并把「放弃 Docusaurus，用 Vite/Next 自建」列为被否方案。偏离发生在原型阶段：`proto/server.py` 用手写的 HTML 把界面跑起来了——那是为了尽快验证 AI 管线与交互决定（掩膜编辑、活页纸、页锚点回写），不是生产形态。本 ADR 把生产形态钉下来，并补上 Tauri 这条新约束。

决定：

- **前端以 Docusaurus 为基。** 应用界面（清单页、审核页、重做页、活页纸）是 Docusaurus 站点里的 React 页面；**考点大纲**这种层级知识树用它原生的文档能力承载——它本来就是一份天然的可导航文档，不该自己写导航。
- **数据不进构建产物**（ADR 0001 的延续）。界面在运行时从写入服务取派生索引；构建只在改代码与发版时跑，**录入一道题绝不触发重建**。
- **写入服务退化为纯数据 API。** 现在它既出 HTML 又出 JSON；生产形态下界面是 React，服务只出 JSON 与静态图片。原型的三个手写视图不迁移，交互按已实测过的决定在 React 里重做。
- **Tauri 兼容是一条架构约束，不是现在要出的产物。** 两条：① 前端产物必须是纯静态 bundle，不依赖 Node 运行时、不做 SSR；② 写入服务必须是一个可被本机进程启动、只监听本机口的独立进程。满足这两条，将来打包只是包一层壳——现在不必付打包 Python + numpy/PIL 的代价。
- **手机上传这条路保留**（ADR 0003 的延续）。写入服务仍监听本机口，手机经 Tailscale 或局域网把照片传进来；界面的形态是浏览器窗口还是 Tauri 窗口，不影响这条通路。录入摩擦最小化是这个项目的生命线。
- **打印走系统默认浏览器，不在 webview 里印。** 活页纸是这套东西一半的价值，而 Tauri 的 webview（Linux 上是 WebKitGTK）里 `window.print()` 的可靠性没有保证——「打不出来」是致命的。所以定：活页纸由系统浏览器打开并打印；若将来要 PDF，由服务侧生成，不依赖 webview。

## 考虑过的替代方案

- **继续用手写 HTML 的 Python 服务当生产形态**：已经跑得通，但路由、组件复用、打印版式都要自己造，且放弃 MDX 与主题生态——ADR 0001 已否过一次。
- **Vite + React 自建**：更轻，运行时能力天然具备；代价是放弃 Docusaurus 的文档能力（考点大纲）与打印版式生态。ADR 0001 权衡过，结论不变。
- **现在就打 Tauri 壳（Python 打成 sidecar）**：能立刻出 app，但把打包与跨平台问题提前引入，而它们与当前要验证的东西无关。
- **现在就用 Rust 重写数据层**：最干净的终态；但擦除、闸门统计、裁剪体检、掌握状态机这些**已被十轮实测**的资产都在 Python 里，重写等于把验过的证据重赌一次。

## 后果

- `proto/` 的定位就此明确：**一次性原型**。它验证的是 AI 管线与交互决定，不是生产代码。它的 HTML 不迁移，但数据格式、提示词、阈值、统计口径与实测结论全部继承。
- 写入服务的接口必须与界面解耦（只剩 JSON），这也让「将来用 Rust 重写服务」变成换实现、不换契约。
- 两个待做 spec（屏幕重做、整页切分）的界面部分按本 ADR 实现；**原型的界面自检不迁移**，那类不变量要在前端的测试里重建。
- **一处新的待验证项**：Docusaurus 以「应用」而非「文档站」的方式使用时，路由与构建产物的形态要实测（尤其 `baseUrl` 与 Tauri 加载本地文件时的相对路径），这是打包之前必须踩掉的坑。

## 修订（前端重构，issue #17）

**决定第 1 条后半句作废**：「**考点大纲**这种层级知识树用它原生的文档能力承载」不再执行。

理由是与 [ADR 0001](0001-file-backed-data-with-write-service.md) 的「数据不进构建产物」正面冲突：索引树的根是**科目**（运行时数据，见 [`CONTEXT.md`](../../CONTEXT.md)），考点大纲挂在科目之下，若交给构建期的 docs 插件，则**录入一道题就会改变这棵树**。改由前端在运行时自绘侧栏，全文见 [ADR 0009](0009-runtime-sidebar-not-docs-plugin.md)。

决定第 1 条**前半句**（应用界面是 Docusaurus 站点里的 React 页面）**不变**，仍然有效。
