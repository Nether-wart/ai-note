# 决定复核（第 1 轮面谈的全部决定）

用途：这份清单是给你**一条条推翻**用的。

- **反转成本**：现在改主意要付的代价（低 = 改个规则或提示词；中 = 牵动两三个模块；高 = 数据模型或整块功能作废）。
- **我的信心**：我对这条决定有多稳。信心低的条目即使你当时选了推荐项，也值得再看一眼。
- **你 vs 我**：标出你偏离了我建议的那几次——那三次恰好决定了这个项目的形状。
- 反转成本高 ≠ 该翻。成本高只说明"翻它要趁现在"。

## 二、三处偏离：现在翻案要付什么

### D1 纸＋屏并重

- **砍屏**（回到"纸为主"）：便宜。屏幕重做复用同一套标准答案与判定逻辑，砍掉只省一个输入框和一个页面；但你会在"不想开打印机"的日子里断掉重做节奏，而节奏一断，7 天间隔就永远凑不齐。
- **砍纸**（回到"屏为主"）：贵。D12、D17、页锚点、版面格、打印批次整块作废——那是你最初点名要的功能。
- **我的判断**：不该翻。真正的成本不在"两条通道"，而在纸那条通道上的四个附属决定。与其翻 D1，不如接受"屏幕是日常节奏、纸是考前强化"。

### D2 拍照自动判定

- **回退到手动标记**：中等成本。页锚点与二维码直达要保留（那是便利的来源），去掉的是上传、识别、判定三步。连带影响：D6 与 D4 的价值大幅缩水——标准答案将只服务屏幕重做。
- **我的判断**：别现在翻，**让原型回答**。这条是全设计里唯一真正的未知，而验证它只要三张照片。若原型显示手写识别可用率过低，回退的代价也就是删掉一个子命令。

### D14 云 VPS ＋ 多用户

- **回退到本机单用户**：数据模型层面几乎免费——因为 D15 已经要求"第一天就带 owner"，单用户只是 owner 数量为 1。真正省掉的是：鉴权、邀请、隔离、配额、备份策略、以及"未成年人敏感信息托管在公网"的合规义务。
- **我的判断**：这是我最建议你重新考虑的一条，但**不是翻掉，而是推迟**：数据模型现在就带 owner，多租户的运营能力放到切片验证通过之后。它不挡任何一条技术验证路径，却能让你在"这东西我自己会不会真用"还没答案之前，不必先建一座机房。

## 三、复核中发现的五个漏洞

这些不是你选错了，而是几条决定叠在一起时没人负责的接缝。

### V1 静默回写没有回执（最严重）

D2（自动回写）＋ D11（先入库后审核）＋ D18（判错清零）叠起来的结果是：**一次误判会在你毫无察觉的情况下把一道毕业的题打回池中，或把一道你其实会的题清零**。

判定结果现在只落在题卡 JSON 里，而你不会去看 JSON。**修法**：每次上传判定照片后必须给一个**回执视图**——列出这一批每道题的判定、置信度、以及"因为看不清所以没判"的，按置信度从低到高排，你可以当场改掉任何一条。

### V2 复习纸会印出未经确认的 AI 正解

D6（正解由 AI 现解）＋ D11（先入库后审核）＋ D12（复习纸含正解）叠起来：你会拿着一份**没人验算过的**正解去复习。**这是整个产品里最坏的失败**——掌握状态判错只影响排程，而错误的正解会影响你学的东西。

**修法**：复习纸默认只印**已审核**的正解；未审核的题只进重做纸（重做纸只需要题面，不需要正解）。这个修法还有个副作用：它让"审核"从一项卫生工作变成一件有回报的事——不审核，你就拿不到复习纸。

### V3 共用考点词表没有治理规则

D14/D15 定了十几人**共用一份考点大纲**、D8 定了受控词表，但没人规定"谁能往词表里加词"。若不定义，实际结果会是两种之一：谁都能加（词表半年后崩成自由标签），或只有你能加（你变成所有人的瓶颈）。**建议**：任何人可提名，进入你的审核队列；同义项的合并权归你。

### V4 两种"降级"混在一起

D11（未审核 → 只能人工确认）与 D16（配额用尽 → 降级人工确认）在界面上表现为同一种状态，但原因完全不同。**修法**：降级必须带原因码，界面文案要能回答"这道题为什么不能自动判"。

### V5 低置信度必须有默认落点，且必须落向"看不清"

D22 定了三值，但没说置信度低时默认落哪边。两种错法的代价不对称：

- 假"**对**" → 推进掌握 → 可能提前毕业 → **你从此不再看到这道题**；
- 假"**错**" → 清零回池 → 题重新出现 → 浪费你的时间，但不会让你漏掉不会的题。

所以低置信度必须落向"看不清"，**绝不能落向"对"**，也不要落向"错"。同时题卡上那条判定要能一键改成人工确认，状态随之回退。

## 四、什么信号出现就该回头翻这条

| 触发信号 | 该翻的条目 |
|---|---|
| 原型显示手写识别或等价判定的可用率低于通过标准 | D2（回退手动标记）、D3（收紧分层）、D13（改输入方式） |
| 你自己的录入+审核耗时超过每题 3 分钟 | D11（改为部分同步确认）、D21（调整审核粒度） |
| 你连续两周没用过重做纸 | D1（砍纸）、D12、D17 |
| 你连续两周没用过屏幕重做 | D1（砍屏）、D13 |
| 实际用户超过 20 人，或有人抱怨看不到自己的数据 | D14/D15（补足隔离与配额）、D16（改成本分摊） |
| 池子里超过 300 道未毕业题 | D5（放宽毕业条件）、D20（缩短首次冷却） |
| "看不清"占比超过 15% | D22（先修拍照与要求，而不是放宽判定） |
| 词表提案一周超过 10 条 | D8（说明词表覆盖不足，该扩的是大纲本身） |

## 五、如果只能翻一条

**D14 的时机，不是 D14 本身。**

理由：它不挡任何一条技术验证路径（原型只需要一个 key 和三张照片），却要在你验证核心价值之前先承担鉴权、隔离、配额、备份与合规五件与"帮我记住错题"无关的工作。数据模型现在带 owner 的成本几乎为零，运营能力后置的成本也几乎为零——这是全清单里唯一一条"推迟毫无代价"的决定。

其次该盯的是 **D2**，而它不需要现在决定：原型会替你决定。

## 六、第 1 轮复核结果（本文件写就之后的裁决）

| 条目 | 裁决 | 影响 |
|---|---|---|
| D2 拍照自动判定 | **翻案**：回退到手动标记 + 页锚点直达 | 纸上判定全部由人给出；一整类失败模式（识别手写、把照片里的题号匹配回数据库、拍虚导致误判）直接消失 |
| V1 静默回写无回执 | 采纳，**但因 D2 翻案而自动消解** | 纸上不再有静默写入；屏幕重做的判定就显示在你眼前。若将来重回自动回写，V1 必须重新捡起来 |
| V5 低置信度落点 | 采纳：一律落向「看不清」，**绝不落向「对」** | 写进自动判定的提示词与阈值 |
| V2 复习纸印未审核正解 | 采纳：复习纸只印**已审核**的正解 | 审核从一项卫生工作变成"拿得到复习纸"的前提 |
| V4 两种降级混同 | 采纳：降级必须带原因码 | 界面要能回答"这道题为什么不能自动判" |
| D14/D15 多租户 | **只推迟运营能力**，数据模型仍立刻带 owner | 见 ADR 0002 的「实施顺序」 |
| D19 默认清单 | 读法澄清（你在复核中提出） | 默认清单不含冷却中的新题；清单页始终有「显示冷却中的题」开关，勾上即可打印它们。这类重做照记为一次重做，但不推进掌握——冷却规则本身已经保证了这一点，不需要额外开关 |

**D2 翻案带来的连锁收益**：原型要验的东西少了一半——最脏的那一段（照片 → 判定）不再需要。自动判定的范围收缩为屏幕重做一个入口，AI 调用量与配额压力同步下降。

**翻案之后新出现的问题，已定**：页锚点的粒度——**每页一个标记**。扫一次打开本页的题目列表，在一屏里连续标记完。选它正是为了对抗活页纸的本性（纸会被抽出来、重排、混在一起）：每页的题目清单在打印时就是已知事实，写在打印批次里，纸怎么挪动都不影响它。

## 七、第 2 轮复核结果

| 条目 | 裁决 | 影响 |
|---|---|---|
| D14/D15 多租户 | **翻案**：直接回到单用户本机 | ADR 0002 作废，见 ADR 0003 |
| D16 配额 | 改写：从"每人每日配额"变成"你自己设的每日上限" | 成本分摊问题消失，它变成一根保险丝 |
| V3 共用词表治理 | **自动消解** | 只有一个用户，词表就是你自己的 |
| 自带 provider / 出境边界 | **自动消解** | 候选池由自己维护，边界收敛为一条白名单常量 |
| 模型自选 | **保留**：按角色配 + 验收上岗 + 视觉探针 | 见 `CONTEXT.md` 的「模型」一节 |

**两轮复核合起来的效果**：D2 翻案砍掉了纸上的自动写入，D14 翻案砍掉了多租户。两者的共同点是——**都不服务于核心循环，却各自带来一整类失败模式**。砍完之后，这个项目第一次收拢成一句能被检验的话：一个跑在自己机器上、能打印、能重做的小工具。

## 八、原型考核之后新增的三条决定

原型跑通了，两条真实照片暴露了三件在纸面上想不出来的事：

| 发现 | 决定 | 记录在 |
|---|---|---|
| 订正的红笔就写在选项上方，矩形裁剪躲不开——重做纸印照片会泄露答案 | **重做纸印题面转录，复习纸印照片** | [ADR 0004](adr/0004-redo-sheet-prints-transcript.md) |
| 题卡 schema 里没有「订正」，两个模型都把红笔订正误当成学生原答 | 新增 **原答** / **订正** 两个领域术语；抽取提示词增加"原答与订正必须分开"；**原答置信度 < 0.6 由系统强制留空** | `CONTEXT.md` |
| 转录文字要印在重做纸上，于是"能否输出可渲染的 LaTeX"从偏好变成硬要求 | 抽取提示词要求数学一律 LaTeX、选择题选项结构化；验收里加 LaTeX 粗检 | `CONTEXT.md`、`proto/README.md` |

第三条是一条**反向传播的后果**，值得单独记下来：一个关于"纸上印什么"的决定，改变了"模型必须输出什么格式"，也就改变了抽取角色的验收标准。设计里的决定不是一层层往下摊的，是会往回顶的。

第 2 条里最值得注意的是**它暴露的失败方向**：把订正误认成原答，会让一道真错题看起来"学生答对了"——而假「对」正是整套设计里唯一被反复防范的那个方向（见「看不清」与成本不对称）。它出现在录入环节，而不是判定环节，说明这条原则必须一路贯到字段层面，不能只在判定那一端设卡。
