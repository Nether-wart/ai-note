# 屏幕重做（含自动判定接入）

**规格正文在 issue 里：<https://github.com/Nether-wart/ai-note/issues/1>**（标签 `ready-for-agent`）。

本仓库的约定是「spec 住在 issue 里」（见 `docs/agents/issue-tracker.md`）。所以这里不留副本：**两份副本会漂移，而这个项目第十轮的教训正是两个产物各说各话、谁都没发现**（验收是对调用记录打的分，题卡却能被后来的路径改坏，中间隔着几十分钟）。正文的完整版本在 git 历史里（基线提交 `c9a2f45`）。

一句话：让「敲一个答案 → 判定 → 进重做历史 → 推进掌握」这条通道存在。判定由写入服务自己问模型、自己映射、自己记来源与置信度——**客户端不碰判定**。
