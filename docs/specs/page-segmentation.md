# 整页切分与错题筛选

**规格正文在 issue 里：<https://github.com/Nether-wart/ai-note/issues/2>**（标签 `ready-for-agent`）。

本仓库的约定是「spec 住在 issue 里」（见 `docs/agents/issue-tracker.md`）。所以这里不留副本：**两份副本会漂移，而这个项目第十轮的教训正是两个产物各说各话、谁都没发现**。正文的完整版本在 git 历史里（基线提交 `c9a2f45`）。

一句话：拍一整页，机器切成题、并且只把**有红笔订正痕迹**的那几道收进库；切错、收错、漏了都能在一个界面上改。没有红笔痕迹的题被明确列出来（可一键补收），不当场丢——漏收一道错题的代价是它永远不在库里，误收一道对题的代价是审核时删掉，几秒。
