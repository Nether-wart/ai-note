# 前端重构：科目索引栏、录入工作台、阅读页

**规格正文在 issue 里：<https://github.com/Nether-wart/ai-note/issues/17>**（标签 `ready-for-agent`）。

本仓库的约定是「spec 住在 issue 里」（见 `docs/agents/issue-tracker.md`）。所以这里不留副本：**两份副本会漂移，而这个项目第十轮的教训正是两个产物各说各话、谁都没发现**（验收是对调用记录打的分，题卡却能被后来的路径改坏，中间隔着几十分钟）。

一句话：把索引交给一棵**运行时**的**科目**树（科目 → 简报／细则／考点大纲／今日重做，另有「未归类」兜底），并让**录入**（上传整页 → 切分 → 人工增删改 → 草稿 → 入库）与**阅读**（每题一页）都在同一个前端里走完——数据仍然运行时取，**录入一道题绝不触发站点重建**（ADR 0001）。
