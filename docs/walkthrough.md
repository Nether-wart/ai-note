# 自己走一遍（人工验收清单）

自动化测试能证明「判据对坏输入会响」，证明不了「打开浏览器一切正常」。这份清单是给人跑的：
**每一步都写了「应该看到什么」和「看到什么就是坏了」。**

> 术语提醒：`CONTEXT.md` 里的**验收**专指*模型上岗*（视觉探针 + 该角色的通过标准，
> 记录在 [`acceptance-log.md`](acceptance-log.md)）。这份清单是**整条链的人工验收**，不是那个。
> 换模型仍然必须重跑那份验收。

## 0. 自动化的那几件（先跑，60 秒）

```bash
python3 -m pytest -q                    # 全绿（727 passed, 2 skipped）
ruff check server/                      # All checks passed!

cd site
npm_config_cache="$PWD/../.npm-cache" npm ci    # 有 lock 文件，用 ci 更可复现
node --test tests/                      # 全绿（#7/#8/#14 的判据，加侧栏树与地址形状那 14 条）
node tests/selftest.mjs                 # 退出码 0：四条不变量成立，且判据对坏夹具会响
npm run build                           # 退出码 0
ls build/index.html build/redo/index.html build/split/index.html
grep -rl "p-2026" build/                # 必须为空
```

**最后三条缺一不可**：构建退出码 0 **且**产物存在 **且** `grep` 为空。构建失败时产物不存在，
`grep` 也是空的——只看 `grep` 会被骗（这个坑真踩过）。

> 退出码 `2` 与 `1` 是两回事：`selftest.mjs` 退 `1` = 界面不变量失败，退 `2` = 这次没跑完
> （环境缺依赖）。环境故障从不冒充界面故障。

**判据自己也会坏**，所以基线要现取：重构前这一批是 **pytest 4 失败 / 自检 exit 1**，
病根是三条判据把「环境」当成了「性质」（报警夹具被一个 proto 遗留物缴械、副作用测试
把证据判成故障、一条断言仓库里恰好没有测试语料）。修完才是 727／38。教训写在这里：
**判据绿着、行为坏着，是这个项目最贵的失败**。

## 1. 起服务与界面

```bash
# 终端 1：后端。默认数据目录在**用户数据目录**；拿仓库里的测试语料跑要显式 --data data
python3 -m server.app --data data --host 127.0.0.1 --port 8765

# 终端 2：界面
cd site
AI_NOTE_API=http://127.0.0.1:8765 npm run start -- --port 3000 --host 127.0.0.1
```

**应该看到**：终端 1 印出三行——数据目录、收件目录、对外地址，然后是监听地址。终端 2 打包完给
`http://127.0.0.1:3000`。

**坏了的样子**：启动直接吐 Python 回溯（D1 不允许）；或者绑 `0.0.0.0` 而启动日志**没有**任何
「手机打不开这个地址」的警告。

## 2. 左侧栏与首页总览（`http://127.0.0.1:3000/`）

**索引以科目为根**（ADR 0009）：首页总览 → 科目 →〔简报｜细则｜考点大纲｜今日重做〕＋ 未归类。

- [ ] 侧栏第一级是**科目**（取值来自 `<数据目录>/vocab/subjects.json`），每个科目展开是那**四栏**；
      最后有**未归类**一项，**道数写在栏上**。
- [ ] **一道题都不许少**：把某一科的题加起来 ＋ 未归类，必须等于索引里的总数。
      随便挑一道题，它必须能在某一栏里找到——**找不到就是缺陷**。
- [ ] 卡上的科目不在词表里时，那一科**仍然出现在树上**并**标出来**（表外），
      不是被藏起来；服务没给某个科目读数时说「读数缺失」，**不许装作 0 道**。
- [ ] 首次打开是构建期渲的 HTML，查询串相关的部分**挂载之后**才读——控制台**不该有**
      hydrate 不匹配的报错。
- [ ] 索引读不到时是一块**带重试**的失败面板，上面有服务的原话、`code`／`reason` 与 `hint`；
      **`warnings[]` 与 `skipped[]` 照原话列出来**，一条都不吞。
- [ ] 首页总览每科目一行：在池／冷却／毕业、未审核、今日份；顶部有合计。
      词表有问题（缺文件／读不了／空的）时，那一条要在显眼处。

## 3. 科目下的四栏（`/subject?name=<科目>&view=<栏>`）

- [ ] `view=` 认不出来时**明确失败**（`data-error-code="view_unknown"`），**绝不**落到第一栏；
      不给 `name` 就是「未归类」那一栏，那不是错误。
- [ ] **简报**：还没有简报时是明确的空态（「这个科目还没有简报」＋「生成」按钮），不是错误；
      生成之后正文与它用到的数字都在，`window_facts`／`history_facts` **照抄服务**、界面不重算；
      简报过期时写清「有 N 道新题没进去」（N 照抄服务的读数）。
      生成失败要照原话显示——尤其是 **502 `brief_unverifiable`**（数字对不上），
      它与「模型没问成」是两件事。
- [ ] **细则**：按**录入时间由新到老**排列；每行有题面（不是全文）、题型、掌握读数、考点、错因，
      整行点进阅读页。**这一页不印答案**（正解／标准答案／原答／订正一个都不许出现）。
      有排不了序的（缺 `created_at`）时显式报出几道。
- [ ] **考点大纲**：章 → 节 → 点；空科目明说「这个科目还没有大纲」，不是一片空白。
- [ ] **今日重做**：与旧的清单页同一套读数——队列在 URL 里、`bases` 那两套口径由开关切换、
      N/M 照服务的原话；界面**不重算**任何一个数。

## 4. 阅读页（`/problem?pid=<题卡 id>`）

- [ ] 题面**默认是擦除手写后的图**；原图只能由那个**显式、带标记**的开关打开；
      缺擦除图时明说「没有擦除手写后的题面图」，**绝不回退到原图**。
- [ ] 正解与标准答案、原解与订正、考点与错因、掌握读数与重做历史都在。
      **答案是这一页该出现的东西**——而首页总览、细则、今日重做都不许印它。
- [ ] 地址里没有 `pid`（或给了空的）→ **明确失败**（`pid_missing`），**绝不**落到某一道题。

## 5. 录入：全屏工作台（首页或细则上的「上传」按钮；`/split?page=<页 id>` 是改已有的一页）

- [ ] 选照片（`accept=image/*`、手机上是 `capture=environment`）或拖拽进来；有一个**科目下拉**
      （选项来自词表，多一个「未归类」）。
- [ ] 提交一个词表里没有的科目 → **400**，面板上是服务的原话与可选值；
      **词表不在**时相反：收下这个科目，但把「没有科目词表」那条警告一起显示出来。
- [ ] 回执里**回显科目**：提交了什么、回执里就是什么；没给就是 `null`（未归类）。
- [ ] 块框叠在整页照片上；能拖边界、画新框、删块、改去留、改题号与题型，每一步都真的提交出去。
      `blocks_removed`／`blocks_added` **含 0 都报**。
- [ ] **删一个已绑卡的块** → 400，服务的原话 ＋ `reason=block_delete_bound_to_card`，
      并且说清「要『不要它』只能用『不收』」。
- [ ] **切分不可用**（`blocks` 是 `null`）不是错误：明说「请在这张照片上自己画框」并直接开放画框。
      切分跑了但抠不出块时也一样——**页照建**，`blocks` 是 `null` 而不是 `[]`。
- [ ] 「重跑切分」是**破坏性**的：先被 **409** 拦下，把将丢弃什么（`manual_blocks`／
      `removed_blocks`／`mode_before`）原话显示出来并**再问一次**，确认后才重置。
- [ ] **入库**：`created`／`reused`／`skipped`／`refused` **逐条**显示，一条都不许吞。
- [ ] 入库或建页成功之后侧栏的道数会跟着变（那是一次写之后的**显式刷新**，
      不是「每页各取一次索引」——那件事由外壳保证只做一次）。

## 6. 手机上传（可选，手机与电脑同一局域网）

```bash
python3 -m server.app --data data --host 0.0.0.0 --port 8765 \
    --public-base http://192.168.1.50:8765      # 换成你电脑的局域网地址
```

- [ ] 手机浏览器打开 `http://192.168.1.50:8765/upload`，能选照片并上传。
- [ ] 上传后文件落进**收件目录**（终端 1 印出来的那个）；`data/inbox/` 不在 `git status` 里。
- [ ] 不传 `--public-base` 而绑 `0.0.0.0` → 启动日志**与**索引里都有「手机打不开」的警告。
- [ ] 一次上传全是空文件 → **400 结构化信封**（不是 500），且收件目录**没有被创建**。
- [ ] `curl -s -X POST http://127.0.0.1:8765/api/inbox/scan` 能手动扫描（没实现目录监视，
      这是它的等价入口；响应里 `watch.implemented: false` 就是在说这件事）。

## 7. 只读与隐私（收尾自查）

- [ ] `git status --short` 里没有 `data/` 下的私人文件、没有 `runs/`、没有 `.env.local`。
- [ ] 用 `--data data` 跑过之后，真数据没被写：`md5sum data/index.json` 与开始前一致。
- [ ] 服务默认只监听本机：`ss -ltn | grep 8765` 显示 `127.0.0.1:8765`（绑 `0.0.0.0` 是你显式要的）。
- [ ] `--data` 不指仓库时，仓库里**不会**多出 `data/inbox/` 或 `runs/`。

## 8. 需要密钥才算数的那部分（模型）

- [ ] 不配 key 时，所有会用到模型的路径都**明确报错**（502 `model_unavailable` 或界面上的明确失败），
      **不静默降级**、不留半截记录、不写坏数据。
- [ ] **一条连带的后果要主动验**：切分角色默认是接上的（`main()` 注入），所以**没有密钥时
      `POST /api/page` 是 502，不会退回手动画框**。想走手动画框那条路，要么配密钥，
      要么显式用 `build_server(..., segmenter=None)` 起服务——那时页照建、`blocks` 是 `null`。
      两种行为都要亲眼见到一次，因为它们看起来像同一件事的两个说法。
- [ ] 配了 key 之后才谈**模型验收**：

```bash
python3 -m pytest server/tests/test_acceptance_models.py -v
```

  三关：**视觉探针**（合成数字图，不需要私人内容）／**真实照片上的人眼判定**
  （本机 `data/pages/*.png`，把框画成 PNG 落在 `.verify/acceptance/`）／
  **三条确定性对账判据**。三条都要过，记录落 `docs/acceptance-log.md`；
  换模型必须重跑（`CONTEXT.md` 的「验收」）。
- [ ] **没配密钥时那条验收必须是 `skip` 而不是 `pass`**——「没跑」不许看起来像「通过了」。
      故意把密钥清掉跑一遍，确认它真的报的是 skipped。

## 什么算不合格（红线）

| 看到这个 | 意味着 |
|---|---|
| 屏幕重做的题面是原图，或缺图时回退到原图 | 违反 ADR 0005：把订正摆在眼前 |
| 拒绝或跳过的响应是裸 500／空体／HTML 回溯 | 违反 ADR 0007 第 6 条与裁决 D1 |
| 越界时悄悄跳回第一题 | 违反 spec #1 验收 3 |
| 界面自己重拼了服务给的文案 | 会印出两句几乎一样的话（里程碑二真撞过一次） |
| 构建产物里搜到真题 id 或题干 | 违反 ADR 0001：公开仓库的静态站点泄露真实作业 |
| 真数据目录里多出／少掉文件 | 最高优先级：那是真实学生的手写作业 |
| 一道题不在侧栏的任何一栏下（含「未归类」） | 违反 ADR 0009 的兜底：**静默少一道题**是这个项目最怕的失败 |
| 提交了科目，回执里却没有它 | 界面从此只能靠猜「我填的到底进没进去」 |
| 删了一个块，页文件的 `removed_blocks[]` 里没有它 | 「删掉它才是静默丢题」——留痕是那条裁决剩下的部分 |
| 简报里的数字在索引里找不到 | 一段读起来很顺、数字却是编的总结：闸门必须当场拦下它 |
| 判据报「通过」，而它其实从没跑过（环境缺依赖、夹具被缴械） | 本条清单最后一次修的就是这一类，**它比没写判据更坏** |
