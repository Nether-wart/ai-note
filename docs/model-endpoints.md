# 模型端点：怎么配、怎么算够格

这一页回答两件事：**想用哪家模型该怎么填**，以及**换了一家之后凭什么说它能上岗**。
接口口径在契约 §10.6 与 [ADR 0010](adr/0010-model-endpoints-are-the-users-choice.md)（端点由你自己选）；
设置文件是**第三层来源**（设置文件 ＞ 环境变量 ＞ 预设默认），改完**立刻生效**。

## 1. 两家预设怎么配

```bash
# .env.local（已在 .gitignore 里）
DASHSCOPE_API_KEY=sk-...
DEEPSEEK_API_KEY=sk-...
```

## 2. 任何 OpenAI 兼容端点怎么配

两条路，任选：

**① 界面（推荐）**：`/settings` → 「加一家」→ 填名字、`base_url`、密钥、默认模型（可留空）
→ 回到上面的角色表把某个角色指过去 → 保存。**改完立刻生效**，不用重启。

**② 环境变量**：

```bash
AI_NOTE_PROVIDER_OPENAI_BASE_URL=https://api.openai.com/v1
AI_NOTE_PROVIDER_OPENAI_API_KEY=sk-...
AI_NOTE_PROVIDER_OPENAI_MODEL=gpt-4o        # 可选，角色也可以各自给模型
EXTRACT_PROVIDER=openai                     # 识图／转录
JUDGE_PROVIDER=ollama                       # 判定可以指向另一家
```

名字里的非字母数字会换成下划线再大写（`my-proxy` → `AI_NOTE_PROVIDER_MY_PROXY_*`）。
**缺 `base_url` 或密钥就是坏配置**：服务拒绝启动（或保存时 400），**不在第一次调用时才 401**。
本机端点不需要密钥时按惯例填一个占位值，**别留空**（留空与忘了填长得一样）。

## 3. 免费／转发类服务：能用，但先读这一段

它们在协议上与任何 OpenAI 兼容端点**没有区别**，所以上面那两条路直接就能配——**不需要改代码**。
要花钱买的不是"能不能填"，而是下面这几件事：

| 免费端点会怎样 | 后果 | 这里怎么办 |
|---|---|---|
| 限流、队列、超时 | 一次重做**判定失败** → 502 `model_unavailable` | 这是**刻意的**：这一次重做**不留任何记录**（不让"没问成"伪造一条没发生过的重做）。界面可以重试 |
| 悄悄换后端模型 | 读数是模型给的，但**你不知道现在是谁在给** | `provenance` 记了 `provider`/`model`。**换模型就要重跑验收**——所以换后端也必须重跑 |
| 服务消失 | 第二天全线 502 | 预设里留着备用的一家；设置页能一键切 |
| 拿你的题当训练语料 | 照片与答案的**去处在变** | 端点是你的选择、代价也是（ADR 0010 的后果那一段）。单用户自用也请把这一条当真 |

**判定角色（`judge`）要格外谨慎**：它出错时这次重做不留记录，所以一个不稳定端点表现为"重做没生效"，
而不是"读错了一道题"——后者你能发现，前者不容易。**宁愿判定用收费的稳端点，识图用免费的。**

## 4. 一个端点够不够格：可执行清单

免费与收费一视同仁。四条都要过，缺一条不算上岗：

```bash
# ① 模型上岗验收（需要密钥；没密钥会 skip，不是 pass）
python3 -m pytest server/tests/test_acceptance_models.py -v
```

- [ ] **② 视觉探针**：拿一张真实整页照片问一次，看它能不能**逐字**读出题面（而不是"讲了个大意"）。
- [ ] **③ 固定照片集上的人工判定**：同一批照片，人工看转录对不对。**切分质量只有人能判**。
- [ ] **④ 三条确定性对账**：`server/segmentation.py` 的题号连续性／重叠／覆盖三条判据必须**全过**。

**换模型就要重跑这四条。** 理由不是仪式：模型的"读法"会变，而变坏的方式通常是
**读起来很顺、内容是错的**——那种错误不会被任何现有判据发现。

## 5. 数学卷子：哪一步可以交给文字模型

**决定（待 OCR 那条路落地时实现）**：数学公式**不按科目分流，按块判定**。

两种坏法要分开：

- **字符级噪声**（`∃` 读成 `3`、`∈` 读成 `E`）：文字模型**能修**，而且相当可靠——
  信息都在，它做的是"把字符流整成 LaTeX"。
- **结构丢失**（分式被拉平、上下标变同行、根号与矩阵没了）：**修不了**。二维结构在文本流里
  根本没被记下来，模型只能**编一个看起来合理的**。

所以一整块 OCR 结果要走三道闸，任一道不过就**退回视觉模型**：

1. **数学符号闸门**：修好的公式里每个数学符号都必须能在 OCR 原文里找到（允许多重集包含，
   加一张很小的结构修正白名单：`{}`、`\frac`、`^`、`_`）。**出现原文没有的符号 → 不许修。**
2. **编辑距离上限**：归一化编辑距离超过阈值＝"在重写而不是修补" → 退回。
3. **两份都留档**（OCR 原文 ＋ 修补结果，进 `provenance`）：修错了要看得见。

⚠ **这一节的阈值与白名单都还没有实测数据**（本地 OCR 还没接上）。要拿真实卷子标出来，
**不许拍脑袋定**。在那之前：数学卷子**继续用视觉模型**。
