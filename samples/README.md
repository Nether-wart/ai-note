# 原型样例照片

把**真实**的手写错题照片放这里。不要用摆拍的干净样例——原型要验的正是真实条件的脏数据（涂改、草稿、光线不匀、题干是印刷体而解答是手写）。

建议两张，覆盖：

1. 印刷体题干 + 你手写的错解（选择题或填空题，用来验自动判定与"原答/订正分离"）；
2. 一道解答题：有解题过程、有涂改（用来验"证明/过程题走人工确认"这个分层是否必要）。

**第三张（可选）**：同一道题的第二次重做。它的原用途——拍下来自动判定——已被第 1 轮复核停用，所以不再是必需；但如果你想量等价性判定在真实手写上的表现，它仍然比纯文本用例更接近实战。

要求：光线正常、不要预先裁剪、尽量保留整页（原型要顺便看版面框切得准不准）。

隐私：这些照片默认留在这台机器上，只有调用云模型的那些请求会把它们送到境内模型服务。`samples/` 已在 `.gitignore` 中，不会被提交进仓库。
